## 7. 第 5 关：CBC 工作模式

密钥 K = 0x2D55；明文 `S-AES CBC mode works on longer messages!`（40 字节）。

### 7.1 加密与 IV 共享

```text
IV（随机生成） : 0001001000110100 (1234)   ← 需与密文一并共享给解密方
密文分组(21 组): bb15 0262 f88f 9c47 9cc1 fdd7 206b f8b2 73de 6992 db89
                 7f33 dbb6 dbe1 2979 9635 26e0 2ac5 a1c8 fa3c f237
解密（同一 IV）: 'S-AES CBC mode works on longer messages!'  ✅ 还原一致
```

| 用例 | 结果 |
|---|---|
| 随机 IV 生成（200 次全部在 16 位范围且高度分散） | ✅ |
| 5 种长度（1/5/40/18(中文)/100 字节）CBC 往返 | ✅ |
| 40 字节明文 → 21 组密文 | ✅ |
| IV 错误 → 解密结果与原文不同（体现 IV 必须共享） | ✅ |
| 同明文同 IV 密文可复现；换 IV 后密文不同 | ✅ |

### 7.2 篡改密文前后解密结果对比

篡改第 1 组密文（按位取反）：

| 项 | 值 |
|---|---|
| 原密文分组 | `bb15 0262 f88f 9c47 ...` |
| 篡改后密文分组 | `bb15 **fd9d** f88f 9c47 ...`（第 1 组被修改） |
| 篡改前解密（分组） | `532d 4145 5320 4342 4320 6d6f ...`（= 原文） |
| 篡改后解密（分组） | `532d **2b94 acdf** 4342 4320 6d6f ...` |
| 受影响明文分组 | **第 1、2 组**（共 21 组），其余 19 组不变 |

```text
篡改前明文：'S-AES CBC mode works on longer messages!'
篡改后明文：'S-+���CBC mode works on longer messages!'   ← 第 1 组乱码、第 2 组对应位变化
```

| 用例 | 结果 |
|---|---|
| 篡改第 1 组：仅第 1、2 组明文受影响，其余 19 组不变 | ✅ |
| 被篡改组（第 1 组）明文整体乱码（4145 -> 2b94） | ✅ |
| 下一组（第 2 组）明文按位翻转（原值与篡改后 XOR = ffff） | ✅ |
| 以新值替换第 2 组：受影响分组仍为 {2,3} | ✅ |
| 篡改末组：末组明文改变、PKCS#7 填充被破坏 | ✅ |

**结论**：CBC 中篡改第 *i* 组密文会导致第 *i* 组明文整体乱码、第 *i+1* 组对应位翻转，错误不会扩散到更远的分组；篡改末组还会破坏填充校验。因此 CBC 对密文篡改有可见的传播特征，但需叠加 MAC 才能获得完整完整性保护。
